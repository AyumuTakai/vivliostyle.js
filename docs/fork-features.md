# このフォークにだけある機能と修正

このリポジトリ（[AyumuTakai/vivliostyle.js](https://github.com/AyumuTakai/vivliostyle.js)）は、公式の [Vivliostyle.js](https://github.com/vivliostyle/vivliostyle.js) の個人用フォークです。公式にない機能と修正をここにまとめます。公式のドキュメント（`docs/` の他のファイル）は、公式の変更を取り込みやすくするため、なるべく変更していません。

公式の変更は定期的に取り込んでいます。取り込むたびに、Karma のテストと、公式との組版結果の比較で、意図した違い以外がないことを確認しています。

## CSS の拡張

### ページ初出のみのルビ（`-viv-ruby-repeat`）

- `-viv-ruby-repeat: auto | hide-on-page`（継承する。初期値は `auto`）
- `hide-on-page` のとき、各ページで、同じ語のルビ（`rt`・`rtc`）を原稿の順で最初の1回だけ表示します。
  - 同じ語かどうかは、親文字とルビの文字列の組で判定します。`ruby` 要素に `data-ruby-key` 属性があれば、その値で判定します（送り仮名や表記の揺れをまとめるときに使います）。
  - 2回目以降のルビは `visibility: hidden` で隠すため、行送り・改行・改ページは `auto` のときと変わりません。
  - 脚注やページフロートの中のルビも数えます。ページマージンボックス（ランニング要素）の中のルビは、数えず、隠しもしません。
- 見開き単位や章単位の初出には対応していません。章単位は組版によらず原稿だけで決まるので、Markdown の変換（VFM のプラグインなど）で扱う方が簡単です。

```css
ruby {
  -viv-ruby-repeat: hide-on-page;
}
```

テスト文書: `packages/core/test/files/ruby-repeat-hide-on-page.html`

## ビューアの DOM

### ページの種類の属性（`data-vivliostyle-page-type`）

名前付きページ（`page` プロパティ）のページのコンテナに、ページの種類の名前を `data-vivliostyle-page-type` 属性で付けます。既定の種類のページには付けません。`data-vivliostyle-spine-index` と合わせて、ページがどの文書のものか、どの `@page` 規則が当たるかを外から判断できます（CLI のフォークの並列ビルドで使っています）。

## 修正

- **2ページ目以降の `<object>`・`<embed>`**: 表示していないページの `<object>`・`<embed>` の中身を、ブラウザーが読み込まないため、組版がそれぞれ 30 秒のタイムアウトを待っていました。ページを隠す前に読み込みを待つようにしました。
  - PDF で空白になる問題は、印刷時にブラウザーが中身を読み込み直すことによるもので、CLI のフォーク側でも対処しています。
- **`<iframe>` の中身の印刷**: 印刷時、Chromium がページのズーム（出力の解像度のためのもの）を `<iframe>` の中の文書に適用しないため、中身が 1/8 の大きさで印刷されていました。印刷の間だけ、同じオリジンの `<iframe>` の文書にズームを設定します。

## 内部の変更

- **非同期処理の `async`/`await` への置き換え**: 組版エンジンの非同期処理を、独自のタスクスケジューラー（`task.ts`）から標準の `async`/`await` に置き換えました。描画の排他制御（`RenderLock`）と、`AbortSignal` による中断を備えています。置き換えたページの表示に失敗したときは、ログに残します。出力は公式と変わりません。
- **性能の改善**: 強制的なスタイル再計算の削減などで、Vivliostyle CLI からの直列ビルドが約 6% 短くなりました（計測に使った 169 ページの本）。
